Классификация связей между таблицами:

1. actors -> movie_cast: один ко многим.
Один актёр может встречаться в нескольких строках movie_cast.

2. movie -> movie_cast: один ко многим.
Один фильм может иметь много записей в movie_cast.

3. director -> movie_direction: один ко многим.
Один режиссёр может быть связан с несколькими фильмами.

4. movie -> movie_direction: один ко многим.
Один фильм может иметь несколько записей в movie_direction.

5. movie -> oscar_awarded: один ко многим.
Один фильм может иметь несколько записей о наградах.

6. actors <-> movie через movie_cast: многие ко многим.

7. director <-> movie через movie_direction: многие ко многим.
